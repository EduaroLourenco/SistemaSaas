## O que não foi capturado, e por quê

| | motivo |
|---|---|
| `/convite/[token]` com token **válido** | exigiria gravar um convite no banco de produção, e visitar o link consome o convite. Capturado só o estado de token inválido. |
| Estados de erro de validação | a conta de captura é `leitor`: não grava, então não há submissão inválida a fotografar |
| Confirmação de exclusão | ação destrutiva, deliberadamente não exercida por roteiro automático |
| `/importar` com prévia carregada | exigiria subir arquivo real |
| `/promocoes/processar` com resultado | exigiria planilha de campanha real |
| Folha lateral aberta nos cadastros | o botão que abre pertence a papel de escrita |
| Erro de rede | exigiria derrubar o Supabase |
| Passagem pelo OAuth do Mercado Livre | sai do sistema para o canal |

**Enquadramento de dobra:** tentei uma segunda passada capturando só o que
cabe na janela, para as telas gigantes ficarem legíveis. O roteiro não
conseguiu autenticar de forma estável no servidor de desenvolvimento (o
formulário submetia antes do React assumir os campos) e a passada foi
descartada em vez de entregue pela metade. **Fica como pendência** — as
capturas de página inteira estão completas e são o que foi pedido.

## Como reproduzir

```bash
npm run dev
node evidencias/capturar.mjs
```

Precisa de `docs/auditoria-visual-2026-10-07/.credencial-teste.json` (fora
do git) e do Chrome instalado. A lista de rotas está em
`evidencias/rotas.mjs`.
